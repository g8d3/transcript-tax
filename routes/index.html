Route mechanics measured while building this (all of it is product-relevant, because the route is part of what the audit measures):

  • opencode-go is not a bare OpenAI-compatible endpoint. A key-only call returns 400 MissingSessionID — Request is missing x-opencode-session and cannot be routed. It routes by harness session, so a session id is part of the route; the matrix sends one.
  • Two routes are funded nowhere: aihubmix answers 403 account balance is insufficient and cerebras answers 402 payment required. They are listed above as unavailable, not as options.
  • Cache-read pricing is a route property, not a model property (same model family: $0.0016/M on one route, $0.044/M on another), so the cache lever is worth what the route charges for it.
  • Several routes return the reply inside a reasoning_content field instead of content, and some deliver it in a single chunk (no measurable first token). That is the same artifact that forced our own rate floor (minStreamMs, e10.3): a window you cannot measure is not a rate.
